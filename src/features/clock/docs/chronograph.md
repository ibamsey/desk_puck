# Chronograph (stopwatch) faces

Asset faces can declare a **chronograph** stopwatch on a subdial. Wall time uses the main hour / minute / second hands; elapsed time uses **`chrono.png`** rotated about **`chrono.subdial`**.

## Manifest

Up to **three subdials** (roles determine what each hand shows):

| Role | Hand angle |
|------|----------------|
| `wall_second` | Wall-clock seconds (always live) |
| `chrono_minute` | Stopwatch minutes (one lap / 60 min) |
| `chrono_second` | Stopwatch seconds (one lap / 60 s) |

```json
"behaviour": { "chronograph": true },
"subdials": [
  { "role": "wall_second", "file": "sub_wall_sec.png", "subdial": { "x": 52, "y": 120 } },
  { "role": "chrono_minute", "file": "sub_chrono_min.png", "subdial": { "x": 120, "y": 52 } },
  { "role": "chrono_second", "file": "sub_chrono_sec.png", "subdial": { "x": 120, "y": 168 } }
]
```

Legacy single `"chrono": { ... }` still packs as one `chrono_second` subdial.

Packer sets flags `0x0004` / `0x0008`. Blob chunk order: hour, minute, [second], [subdial×N], [hub].

## Touch (Clock screen only)

| Gesture | Action |
|---------|--------|
| **Single tap** | Start if stopped; stop if running |
| **Double tap** | Reset to 0 and stop |

Swipes unchanged (up/down change face; reset on face change). Non-chronograph faces ignore tap/double-tap.

Chrono subdials use elapsed stopwatch time (frozen while stopped). **Classic Chrono** uses all three roles above; centre hands are hour + minute only.
