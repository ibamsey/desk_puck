# New asset face template

Copy this folder to `faces/<your-slug>/` (without the leading `_`), add PNGs + `face.json`, then run `python tools/watch_face_pack.py`.

See [authoring-spec.md](../../../docs/authoring-spec.md), [ai-watch-face-agent.md](../../../docs/ai-watch-face-agent.md), and [assets/README.md](../../README.md).

Put JPG/PSD/prompts under `source/` in your slug folder — the packer ignores that subfolder.
